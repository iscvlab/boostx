# `/contextx` (Context & Compaction Diagnostic)

Inspect the active Antigravity conversation transcript (`transcript.jsonl`), determine the exact **Context Compaction Round**, total session steps, and evaluate the risk of memory drift and hallucination.

Portable across Windows, macOS, and Linux. Zero external dependencies (Python standard library only).

Red failure modes to prevent:
1. Pushing long pair-programming sessions past Round 2+ where the model suffers from silent memory degradation and hallucinations.
2. Incurring unexpected IDE gRPC/session timeout crashes from bloated conversation transcripts.
3. Guessing the compaction count from memory instead of inspecting the deterministic transcript checkpoints.

## Standard Operating Procedure (Every Run)

### Step 1: Execute the Diagnostic Script

Run the deterministic context analyzer:

**Cross-Platform Command**:
```bash
python .agents/skills/contextx/scripts/check_context.py
```

*Or via global path*:
* Windows: `python "%USERPROFILE%\.gemini\config\skills\contextx\scripts\check_context.py"`
* macOS/Linux: `python ~/.gemini/config/skills/contextx/scripts/check_context.py`

*(Optional: pass `--conv-id <id>` if targeting a specific historical session).*

### Step 2: Evaluate the Health Rubric

The script parses `transcript.jsonl` checkpoints and scores context health:

| Compaction Round | Total Steps | Health Level | Memory Risk | Recommended Action |
| :---: | :---: | :--- | :--- | :--- |
| **Round 0** | < 120 | 🟢 **HEALTHY** | None (100% full context retention) | Continue work in current chat. |
| **Round 1** | 120–250 | 🟡 **NOMINAL** | Low (recent history preserved) | Continue work; keep edits focused. |
| **Round 2** | 250–350 | 🟠 **CAUTION** | Moderate (early negative constraints drifting) | Wrap up the active milestone soon. |
| **Round 3+** | > 350 | 🔴 **CRITICAL** | High (frequent truncation, hallucination risk) | **Start a fresh chat immediately.** |

### Step 3: Present Scorecard & Guide Next Step

1. Output the markdown scorecard generated by `check_context.py`.
2. If status is **CAUTION** or **CRITICAL**:
   * Alert the user about the risk of structural hallucinations and session timeouts.
   * Advise the user: *"Run `/kickoffx` to verify document sync, review next-phase options, and generate a pristine prompt for your fresh conversation."*
3. If status is **HEALTHY** or **NOMINAL**:
   * Confirm that context is clean and proceed with normal task execution.
